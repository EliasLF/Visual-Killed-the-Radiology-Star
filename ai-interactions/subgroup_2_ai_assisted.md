# Generative AI Interaction Log – Subgroup 2 (AI-assisted)

## 1. Tools Used

During Phase I, our subgroup used two Generative AI tools:

- **ChatGPT** : https://chatgpt.com/
- **Claude.ai** : https://claude.ai/

We used these tools as assistants throughout the project to support our understanding, implementation, debugging, and analysis.

## 2. Understanding the Project and Its Objectives

**Purpose:** To understand the assignment requirements, the project's objectives, and the experimental tasks.

**Example prompts:**
- "Can you explain the project requirements in simple terms and describe what we are expected to investigate during Phase I?"
- "Can you explain the objective of our project and how BiomedCLIP is used for medical image-text retrieval and zero-shot classification?"

**How AI helped:**

The tools provided explanations of the project structure. This helped us clarify the overall direction of the project.

## 3. Understanding the Model – BiomedCLIP

**Purpose:** To understand the architecture and functionality of BiomedCLIP.

**Example prompts:**
- "Explain BiomedCLIP and how its image encoder and text encoder work together."
- "Explain zero-shot classification and how it works with BiomedCLIP without additional training."

**How AI helped:**

These explanations helped us understand the theoretical background behind our experiments.

## 4. Understanding the Datasets

**Purpose:** To understand the structure, content, and suitability of the selected datasets.

**Example prompts:**
- "Can you explain the ROCOv2 dataset and describe the information provided for each image?"
- "What is the difference between image captions, medical concepts, and modality labels?"
- "What should we check before using a radiology dataset in our experiments?"

**How AI helped:**

The tools helped us understand the different types of information available in our datasets, including radiology images, textual captions, medical concepts, and imaging modality labels.


## 5. Pseudocode to Python Code Generation

**Purpose:** To support the implementation of experiments by converting our planned logic and pseudocode into Python code.

**Example prompts:**
- "Here is our pseudocode for the experiment. Can you translate it into Python code using the appropriate libraries?"
- "Can you turn this basic implementation into a more structured and sophisticated version while keeping the same logic?"
- "Can you add the necessary functions, error handling, and comments to make the code easier to understand?"

**How AI helped:**

One important use of Generative AI was transforming our own pseudocode and planned experimental steps into more complete Python implementations.

The AI tools suggested suitable libraries, organized the implementation into functions, and provided additional technical details that were not explicitly included in the initial pseudocode.

However, the generated code was not automatically considered correct. We still needed to review the implementation, understand the generated functions, adapt the code to our dataset and environment, and test whether it produced the expected results.

This demonstrated both the usefulness of AI for accelerating implementation and the importance of human verification.

We used Claude for this part, cause we found it more structurable.

## 6. Critical Evaluation: Strengths and Limitations

### Strengths

- Helped us understand unfamiliar concepts and the model architecture.
- Provided explanations of datasets and experimental approaches.
- Helped us understand existing Python code.
- Supported debugging and troubleshooting.
- Converted pseudocode into more complete Python implementations.
- Suggested ways to structure and improve code.

### Limitations

- Some explanations required additional clarification.
- Generated code could be more complicated than our original implementation.
- Suggested implementations needed to be checked for compatibility with our environment and datasets.
- AI-generated code and explanations could not be assumed to be correct without testing and verification.
- We still needed to understand the code ourselves rather than simply copying and executing it.

## 8. Overall Evaluation

Overall, ChatGPT and Claude.ai were useful supporting tools during Phase I. They helped us understand the project, explore the datasets, learn how BiomedCLIP works, and implement parts of our experiments.

One particularly useful aspect was the ability to provide pseudocode and receive a more complete Python implementation in return. This helped us move from an experimental idea to an executable implementation more efficiently.

At the same time, we learned that generated code can be unnecessarily complex or require modifications. Therefore, we treated AI-generated content as suggestions that needed to be reviewed, understood, tested, and verified before being integrated into our project.

The experience showed that Generative AI can support both learning and implementation, but critical thinking and independent evaluation remain essential.
